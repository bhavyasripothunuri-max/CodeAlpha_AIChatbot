# CodeAlpha AI Chatbot

## 📌 Project Overview

CodeAlpha AI Chatbot is a web-based chatbot developed using HTML, CSS, and JavaScript. The chatbot interacts with users through a simple chat interface and provides responses to programming-related questions using rule-based Natural Language Processing (NLP) techniques.

This project was developed as part of the CodeAlpha Java Programming Internship.

---
## Java Implementation

The project includes a Java console-based chatbot implementation (`ChatBot.java`) demonstrating Java programming concepts such as:

- Conditional Statements
- Loops
- User Input Handling
- String Processing
- Object-Oriented Structure

## 🚀 Features

- Interactive chatbot interface
- Modern and responsive UI
- Chat bubble messaging system
- Welcome message on startup
- Timestamps for messages
- Enter key support
- Typing delay simulation
- Rule-based AI responses
- Programming-related question handling
- User-friendly design

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

OR

Run a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
